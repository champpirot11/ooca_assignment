# ooca · ร้านแผ่นเสียงฟังใจ

**A Small Mental Health Experience** — งานออกแบบสำหรับการสัมภาษณ์ตำแหน่ง UX/UI Designer ที่ ooca

- **เว็บ (เล่นบนมือถือ):** https://champpirot11.github.io/ooca_assignment/
- **Figma:** _ใส่ลิงก์ Figma_
- ผู้ออกแบบ: ภานุพงศ์ เพ็งอ่วม

## คอนเซปต์

ร้านแผ่นเสียงเล็กๆ ที่ซ่อนอยู่ข้างทาง ฝนคือเรื่องหนักใจที่ผู้ใช้เจอมา ส่วนร้านคือที่หลบฝน
ผู้ใช้เดินเข้าร้าน เล่าให้ mooca (เจ้าของร้าน มาสคอตของ ooca) ฟังผ่านคำถามสั้นๆ 5 ข้อ แล้วได้แผ่นเสียงหนึ่งแผ่นที่เลือกมาให้ตามอารมณ์ตอนนั้น
จบด้วยใบเสร็จที่มีประโยคให้กำลังใจ บันทึกเป็นภาพเก็บไว้ได้ และมีทางไปคุยกับนักจิตวิทยาของ ooca เสมอ

ใช้เวลาประมาณ 5–10 นาที ไม่ต้องสมัคร ไม่เก็บข้อมูล ทุกอย่างอยู่ในเครื่องผู้ใช้เท่านั้น

## ประสบการณ์ทั้งหมด

1. **หน้าแรก** — mooca กางร่มกลางฝน ปุ่ม "เข้าไปหลบฝน"
2. **บทเกริ่น 5 ฉาก** — ฝนในใจ → มือรับฝน → เดินไปเรื่อยๆ → เห็นแสงไฟ → หน้าร้าน (ข้ามได้ ย้อนได้)
3. **ในร้าน** — mooca ยื่นผ้าเช็ดตัว แล้วชวนตอบ 5 ข้อ (ข้ามได้ทุกข้อ)
   1. ช่วงนี้หนักใจเรื่องอะไร (ฉีกกระดาษฝากไว้ เลือกได้หลายเรื่อง)
   2. ฝนในใจตกหนักแค่ไหน (ฝนในร้านตกตามที่เลือก)
   3. แบตเตอรี่ในใจเหลือเท่าไหร่
   4. ถ้าช่วงนี้เป็นเพลง จะเป็นแนวไหน (เลือกได้ 2 ข้อ)
   5. มีอะไรอยากฝากไว้ไหม (พิมพ์สั้นๆ หรือข้ามได้)
4. **ฟังเพลง** — mooca หาแผ่นให้ วางเข็ม แล้วเล่นเพลงผ่าน SoundCloud พร้อมความหมายของเพลงในภาษาของเราเอง
5. **ใบเสร็จ** — สรุปแผ่นเสียงที่ได้ ประโยคกำลังใจตามเรื่องที่เลือก สิ่งเล็กๆ ที่ลองทำได้ใน 1 นาที และเบอร์ช่วยเหลือ

### การเลือกเพลง

ให้คะแนนทุกเพลง (24 เพลง 8 อารมณ์) จากคำตอบทุกข้อ: แนวเพลงข้อ 4 มีน้ำหนักมากที่สุด รองลงมาคือเรื่องที่เลือกในข้อ 1
ความแรงของฝนและแบตเตอรี่ใจจำกัดว่าเพลงไม่ควรเร็วหรือแรงเกินไป และไม่สุ่มได้เพลงซ้ำกับครั้งก่อนติดกัน
ทุกเพลงเป็นเวอร์ชันมีคนร้อง และตรวจแล้วว่าเปิดในประเทศไทยได้

## ความปลอดภัยของผู้ใช้

- ถ้าแบตเตอรี่ใจเหลือ 10% หรือน้อยกว่า (หรือ 20% คู่กับฝนระดับพายุ) mooca จะหยุดถามก่อน แล้วถามว่าเหนื่อยมากไหม พร้อมปุ่มโทร **1323** (สายด่วนสุขภาพจิต 24 ชม.), คุยกับนักจิตวิทยา ooca และ **1669** — เลือก "ขอนั่งต่อ" ได้เสมอ ไม่บังคับ
- ถ้าข้อความในข้อ 5 มีคำที่อาจสื่อถึงการทำร้ายตัวเอง จะขึ้นการ์ดดูแลแบบเดียวกันก่อนไปต่อ (รายการคำเป็นร่าง ควรให้นักจิตวิทยาตรวจ)
- คนที่อยู่ในทางใจหนักจะได้เพลงที่เบาและช้าเท่านั้น และใบเสร็จจะไม่ชวนทำกิจกรรมเพิ่ม
- ปุ่ม "อยากคุยกับใครสักคน" อยู่มุมบนตลอดการเล่น
- ข้อความที่พิมพ์ไม่ถูกส่งไปไหน ไม่มีระบบหลังบ้าน ไม่มี AI ตอบสด ทุกคำตอบเป็นข้อความที่เขียนไว้ล่วงหน้า

## การออกแบบเพื่อการใช้งาน

- ออกแบบสำหรับมือถือเป็นหลัก (กริด 390×844) และเปิดบนคอมได้ในกรอบมือถือ
- Touch target ≥ 44px, เคารพ safe area ของมือถือ
- ข้ามได้ทุกข้อ ย้อนกลับได้ และจำคำตอบไว้ให้
- มีเสียงฝนและเพลงคลอ เริ่มหลังผู้ใช้แตะครั้งแรก และปิดเสียงได้ตลอด (ปิดเพลงด้วย)
- เคารพ `prefers-reduced-motion` และใช้ข้อความจริงทั้งหมด (อ่านด้วย screen reader ได้)

## รันในเครื่อง

```bash
npm install
npm run dev            # http://localhost:5173 (เปิดโหมดมือถือของเบราว์เซอร์)
npm run build          # dist/ สำหรับขึ้น GitHub Pages
```

พารามิเตอร์สำหรับทดสอบ: `?step=3` เริ่มที่บทเกริ่นฉาก 3 · `?talk=1` เข้าร้านเลย · `?song=calm-0` ไปหน้าฟังเพลง

## โครงสร้าง

```
src/
  main.js              ลำดับหน้าแรก → บทเกริ่น → ร้าน, ปุ่มกลับ/ข้าม/เสียง
  style.css, shop.css  สไตล์ (หน่วย --u = 1px ของดีไซน์ 390×844)
  pages/
    home.js            หน้าแรก
    rain.js, hand.js   บทเกริ่นฉาก 1–2 (วิดีโอวนลูป)
    walk.js, shop.js   บทเกริ่นฉาก 3–5
    shopflow.js        ฉากในร้าน คำถาม 5 ข้อ เครื่องเล่นแผ่นเสียง ใบเสร็จ
    shopdata.js        คำถาม คำตอบของ mooca รายการเพลง ตรรกะเลือกเพลง คำเสี่ยง
    receipt-image.js   สร้างภาพใบเสร็จสำหรับบันทึก
  lib/                 เสียง ฝน วงน้ำ ท่าเดิน
  art/                 ภาพประกอบ ตัวละคร วิดีโอ เสียง
```

## การใช้ AI

- **งานออกแบบทั้งหมด ผู้ทำออกแบบและวาดเอง** ใน Figma: คอนเซปต์ ภาพประกอบทุกฉาก หน้าร้าน ปกแผ่นเสียง เลย์เอาต์ทุกหน้าจอ และ user flow
- **ตัวละคร mooca เป็นมาสคอตของ ooca** ผู้ทำนำมาปรับท่าทาง และวาดเพิ่มเติมเองในบางส่วน (เช่น ท่ากางร่ม ถือผ้าเช็ดตัว ใส่หูฟัง ท่าเดิน)
- **ไม่มีภาพที่ AI วาดอยู่ในงานนี้** — ระหว่างทำมีการให้ AI ลองวาดฉากเป็นตัวอย่าง แต่ไม่ได้นำมาใช้เลย
- **โค้ดเขียนด้วยความช่วยเหลือของ Claude (Anthropic)** — ผู้ทำกำหนดการเคลื่อนไหว จังหวะ และพฤติกรรมทั้งหมด แล้วตรวจเทียบกับดีไซน์และทดสอบเอง
- AI ช่วยร่างข้อความบางส่วน (บทพูด ความหมายของเพลง) ซึ่งผู้ทำตรวจแก้ทุกบรรทัด และช่วยค้นหาเพลงที่เปิดในไทยได้
